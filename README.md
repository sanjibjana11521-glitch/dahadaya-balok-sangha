# Dahadaya Balok Sangha — Static Website

This project is a plain HTML, CSS, and JavaScript website prepared for GitHub Pages.

## Files
- `index.html` — homepage
- `members.html` — members list
- `css/style.css` — styles
- `js/site.js` — mobile navigation, Kali Puja countdown, and programme toggle
- `images/` — club logo and puja programme poster

## Run locally
Open `index.html` in a browser, or use a local static server.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the deployment and open the Pages URL shown there.

No Java, Maven, Spring Boot, Thymeleaf, or database is required.
